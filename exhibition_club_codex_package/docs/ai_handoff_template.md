# Claude Code ↔ Codex 작업 인수인계 서식

복사해서 필요한 항목만 채운다. 확인하지 않은 내용은 비워 두지 말고 `확인 필요`라고 표시한다.

## 공통 인수인계

```text
작업 제목:
작성일·확인 기준 시각:
보내는 쪽: Claude | Codex | 사용자
받는 쪽: Claude | Codex | 사용자·운영장

1. 목표
- 이번 작업으로 만들거나 확인할 결과:
- 최종 사용자: 운영진 | 전체 회원 | 참여자 | 공개 웹 방문자

2. 작업 종류와 권한
- 작업 종류: 설명 | 검토 | 기획 | 가안 작성 | 구현 | 게시·배포
- 허용된 변경:
- 명시적으로 제외한 대상:
- 외부 상태 변경 승인: 없음 | 있음(범위 기재)

3. 정본과 참고 자료
- 정본 문서·파일:
- 문서 ID·경로:
- 실제 확인일:
- 참고 자료:
- 기준 커밋·브랜치·diff:

4. 확정된 사실
-

5. 운영안·시범안
-

6. 확인 필요·충돌
- 항목:
  - 서로 다른 내용:
  - 판단에 필요한 근거:
  - 결정자: 사용자 | 운영장 | 운영진

7. 산출물과 변경 범위
- 새로 만든 파일·문서:
- 수정한 파일·문서:
- 건드리지 않은 기존 원본:
- 관련 링크:

8. 개인정보와 비공개 제외 사항
- 제외한 원본 대화·연락처·개인 응답:
- 운영진 내부 링크 비공개 여부:
- 회원·공개용 결과의 비식별 처리:

9. 실행한 확인
- 원본 읽기 확인:
- 문서 간 정합성:
- 맞춤법·가독성:
- Google 문서 공유 권한:
- Form 응답자 화면·제출 가능 여부:
- 코드·문서 검사:
- 확인하지 못한 항목:

10. 다음 행동
- 다음 담당자:
- 해야 할 일:
- 완료 조건:
- 사용자·운영장 승인 질문:

11. 금지·주의
- 기존 Google 원본 덮어쓰기 금지 여부:
- Git 커밋·배포 금지 여부:
- 공개하면 안 되는 정보:
```

## Claude → Codex 구현 인계 시 추가 항목

```text
구현 지시
- 적용할 승인 문안:
- 대상 파일 또는 Google 문서:
- 유지해야 할 구조·서식:
- 링크·색상·굵게 등 표시 요구:
- 새 파일이면 권장 제목과 저장 위치:

수용 기준
- 최종 문서에서 반드시 보여야 할 문구:
- 반드시 없어야 할 문구·정보:
- Google Docs·Sheets·Forms별 확인 방법:
- 사용자에게 돌려줄 최종 링크와 상태:
```

```text
- 실행한 검사와 결과:

- 공유 권한 확인 결과:
- Form 실제 응답자 화면 결과:
- 공개 화면 확인 결과:

집중 검토 요청
- 사실·날짜 정합성:

```

## 짧은 인계 예시

```text
목표: 2026-08-09 회의 결정에 맞춘 회원 안내 가안 검토
작업 종류: 읽기 전용 검토
정본: 운영규정 전체본, 운영진 회의록 / 2026-08-11 확인
확정: 전체본을 공식 규정으로 사용하고 압축본을 함께 안내
확인 필요: 운영규정 시행일, Form 현재 응답 수집 상태
제외: 운영진 내부 시트 URL, 원본 응답, 연락처, 비공개 대화
다음 담당자: Codex
다음 행동: 승인된 문안만 별도 Google 문서에 반영하고 읽기·권한·Form 상태 확인
주의: 기존 Google 원본은 수정하지 않고 Git 커밋·배포도 하지 않음
```
